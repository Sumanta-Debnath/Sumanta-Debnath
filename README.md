### 🧪 Security Projects & Hands-On Work

**[Subdomain-Enumeration](https://github.com/Sumanta-Debnath/Subdomain-Enumeration)** — Python
<br/>
A wordlist-based subdomain enumeration tool that brute-forces and discovers subdomains for a given target domain. Built for reconnaissance during security testing and pentesting — the first step in mapping an application's attack surface.

**[Visual-Network-Tracker](https://github.com/Sumanta-Debnath/Visual-Network-Tracker)** — Python
<br/>
Captured live network traffic with Wireshark and parsed the resulting `.pcap` files in Python to extract source/destination IPs, ports, protocols, and packet sizes. Geolocated traffic endpoints via GeoIP data and the Google Maps API to visualize communication patterns — hands-on practice in network traffic analysis and monitoring.

**[Python-Phone-Number-Searching](https://github.com/Sumanta-Debnath/Python-Phone-Number-Searching)** — Python
<br/>
An OSINT-style script using the `phonenumbers` library to extract carrier and approximate geographic metadata from a phone number — practicing the information-gathering techniques used during reconnaissance.

**[BMW-Motorrad](https://github.com/Sumanta-Debnath/BMW-Motorrad)** — HTML/CSS
<br/>
A front-end web application built to practice core web fundamentals (HTML, CSS, DOM scripting). Understanding how web applications are structured and rendered is foundational to being able to secure them.
